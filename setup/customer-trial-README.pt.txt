GESTÃO DE OFICINAS — VERSÃO DE TESTE PARA WINDOWS

Esta é uma versão de teste para um único computador. Mantenha a aplicação
antiga e as suas cópias de segurança. Não use esta versão como substituição
definitiva até os resultados terem sido confirmados.

1. Nas propriedades do ficheiro ZIP, selecione "Desbloquear" se essa opção
   aparecer. Depois extraia toda a pasta recebida para o computador. Não execute o programa
   diretamente dentro do ficheiro ZIP. Mantenha juntos INICIAR.exe, o programa
   Gestao Oficinas e a pasta service.
2. Execute INICIAR.exe. O Windows pode apresentar um aviso porque esta versão
   ainda não tem assinatura digital. Se o Windows perguntar, contacte a pessoa
   que lhe enviou a pasta antes de continuar.
3. Para importar os dados antigos, feche primeiro o programa WINDEV em todos
   os computadores que possam escrever nesses ficheiros. Tenha uma cópia de
   segurança atual. Escolha a pasta dos ficheiros .FIC e a análise .WDD
   correspondente quando solicitado. É necessário o driver oficial ODBC HFSQL
   28 de 32 bits instalado neste computador. Caso não esteja disponível, peça
   ao responsável uma exportação SQLite verificada e escolha essa opção.
4. A aplicação cria uma cópia privada, verifica o conteúdo e importa os dados
   para uma base de dados nova. A operação pode demorar vários minutos. Não
   desligue o computador durante este processo. Os ficheiros antigos não são
   alterados pela importação.
5. No primeiro acesso, selecione o utilizador quando pedido e escolha uma
   palavra-passe nova. Não reutilize a palavra-passe antiga.
6. Feche a aplicação normalmente antes de desligar o computador. Se aparecer
   uma mensagem de erro, não apague pastas nem tente reinstalar por cima dos
   dados: contacte o responsável pela instalação.

Os dados de teste e as cópias intermédias ficam numa pasta privada do utilizador
Windows, fora desta pasta. Não envie essa pasta ou os seus ficheiros por email
ou partilha pública. A pasta recebida não contém dados de clientes.

Esta versão não instala atualizações nem faz cópias de segurança automáticas.
Uma atualização, recuperação após falha de energia, impressão e integração com
equipamentos devem ser verificadas separadamente antes do uso definitivo.

GESTÃO DE OFICINAS — INSTALAÇÃO DE TESTE PARA WINDOWS

Esta versão destina-se a testes num único computador. Mantenha o programa
antigo e uma cópia de segurança atual. Não substitua o sistema antigo até os
dados e os procedimentos terem sido confirmados.

1. Execute o instalador e siga as instruções. A versão de teste ainda não tem
   assinatura digital; o Windows poderá apresentar um aviso de segurança.
   Se tiver dúvidas, confirme a origem junto da pessoa que enviou o instalador.
2. Abra Gestão de Oficinas pelo menu Iniciar. Na primeira execução, o assistente
   permite escolher os dados antigos ou começar com uma base de dados vazia.
3. Para importar WINDEV/HFSQL, feche o programa antigo em todos os computadores
   que possam alterar os ficheiros e tenha uma cópia de segurança atual. Escolha
   a pasta do programa antigo ou a pasta dos ficheiros .FIC. A análise .WDD é
   procurada automaticamente; se houver dúvida, será necessário escolhê-la.
   É necessário o driver oficial ODBC HFSQL 28 de 32 bits instalado neste computador. Se não
   estiver disponível, peça uma exportação SQLite verificada ao responsável.
4. Confirme a pasta apresentada e selecione "Migrar dados". Acompanhe as etapas
   de preparação no ecrã; pode demorar vários minutos. Os ficheiros antigos não
   são alterados. Quando terminar, selecione "Continuar para a aplicação". Na
   primeira entrada, escolha o utilizador e uma palavra-passe nova; não reutilize
   a palavra-passe antiga.
5. Os dados são guardados numa pasta privada do utilizador Windows, fora da pasta
   do programa. A remoção do programa não apaga essa base de dados. Não envie
   os ficheiros de dados ou cópias de segurança por canais públicos.

Esta versão não faz cópias de segurança automáticas nem atualizações seguras.
Se ocorrer um erro, não apague pastas nem reinstale por cima dos dados: contacte
o responsável. Impressoras, equipamentos e recuperação após falhas precisam de
ser verificados antes da utilização definitiva.

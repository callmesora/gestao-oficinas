# ADR-012 — Table search and saved visibility defaults

- Date: 2026-10-25
- Status: Accepted by delegated default; runtime confirmation remains open
- Rows: RULE-CC16AB27-028, U-CC16AB27-01/02; no parity promotion
- Supersedes only ADR-003's width/order-only saved payload restriction, adding visibility from the evidenced configuration affordance; all other ADR-003 rules remain.

## Evidence

The complete customer list dossier/spec enables With search on all seven columns and Saves col. config. on TABLE_Clientes. docs/evidence/images/WIN_Table_Clientes.jpg shows header magnifiers and the right-edge configuration affordance. The [PC SOFT AAF manual](https://www.pcsoft-windev-webdev.com/windev-user-documentation-for-aaf.pdf), search-column section, describes header entry, sorting by that column and selecting the first prefix match. This is distinct from the source EDT_termo_pesquisa HFilter. Exact current-version menus, captions, keyboard precedence and locale remain U items; documentation alone is not a recorded legacy runtime.

## Decision

Implement search in the column header, preserving all rows of the active server filter. Request ascending sorting through the existing validated real API, then select the first prefix match in that result. Use raw decimal code strings and ADR-009 lowercase text comparison without trimming or accent normalization. No match/blank input preserves existing selection; no arbitrary fallback. Escape closes only the header input, Enter returns focus to the table; both stop propagation to list activation/closure. These interaction edges are assumed reversible defaults. Do not persist search text, sort, selection or business data as column configuration.

Extend the existing version-1 TableLayout with optional hidden qualified column paths. Older width/order settings remain valid and retain their values; no destructive storage migration. Reconciliation discards stale/source-invisible paths. A source-hidden column cannot be exposed; hiding does not discard width/order. A compact configuration panel lists source column captions as checkboxes. Keep at least one column visible so the table remains usable; allow recovery through the panel and Repor reset. New captions Colunas/Pesquisar/Repor and panel geometry/icons are target defaults, not verified legacy text or appearance. Source-proven customer, descriptive-state and terminal consumers opt in; C2 also enables the evidenced vehicle/unit columns. Vehicle Cliente searches the query description projection, year/month use explicit string prefix comparison, and the active query filter remains independent from visible mode/text (ADR-010). Hidden unit identifier stays unavailable.

Mecânicos consumer: source explicitly sorts col_inativo at initialization, successful add, every edit result and successful deletion. Reset those reads to ascending inativo even after a manual header sort; editing needs only selected-id read before opening, not a source-invented full-list refresh. Known false precedes true; NULL placement/ties retain U-C44F7892-02 (target PostgreSQL NULLS LAST/internal-id tie fallback is a reversible implementation choice, not pinned as legacy order). Header search uses raw String(Codigo), exact description lowercase and Boolean "0"/"1" (NULL empty), an assumed reversible target representation for the checkbox magnifier; native Boolean search wording remains U01/U02. Hidden mecanicosID stays unavailable in configuration and is absent from list DTOs. No active-only filter is invented. Description is an eligible Text/key assisted-input consumer of ADR-003.

Repair-state consumer (MIG-7I, before translation): generated COL_Tipo is Text bound to byte tipo, and row event129–146 replaces known1..8 with the exact source labels (including list “Recepçao”). Sort/search the displayed text through an explicit whitelisted CASE projection, falling back to raw decimal text/empty NULL for unknown values; this is a reversible target default under U-CEBED898-02, not recovered native numeric/display coercion. Preserve all rows and the active source filter contract; ordinary management has no invented filter. Description assistance is eligible Text/key; Codigo and numeric Cor are not. Source-defined column widths69/273/145 and all table options remain authoritative.

## Verification

Exercise actual customer/session/API/PostgreSQL data through header search, selected observation, unchanged row set and caller result. Hide a column, resize/reorder others, reload and restore visibility without losing the layout. Preserve stale-read guards, actual golden/browser checks and visual floors. No business or production auth/schema change. Broader context-menu filters/exports and original runtime/native behavior remain explicit follow-up obligations; this ADR does not exclude them.

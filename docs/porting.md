The first implementation of each pattern must replace its reserved shape with actual symbols/tests in this document. No empty helper or adapter may satisfy a parity row. A missing pattern is added before its construct is ported, reviewed with the slice, and reused thereafter.

Shared skin primitives now start in src/ui/legacy/wd.tsx (WdFrame, WdButton, WdEdit). layout.ts resolves qualified control paths and checked image/state files; geometry/captions come from generated inputs. Frame actions are required in-app callbacks, never native-window commands. ui-check/skin-controls.flows.spec.ts proves component state/assets/geometry; skin_visual_check.py checks component regions only. Full windows, tables, awaited dialogs and business bindings remain in their owning stages.

The next primitives are WdMemo in wd.tsx and WdTable in table.tsx: controlled text and row selection, qualified source columns, caller-provided stable row identities and activation/sort callbacks. TanStack Table 8 manages the row model only; it never invents a business comparator, initial selection or refresh. Table search, saved column configuration and HFSQL cursor coupling remain obligations of each workflow, including U-CC16AB27-02.

Info/Error/YesNo/Confirm/Warning/OKCancel now start in dialogs.tsx: DialogProvider/useDialogs().message returns an awaited numeric result; MessageController queues concurrent calls and settles only the active request. messageModel preserves WINDEVMESSAGEBOX's explicit 1/2/6/7 values (type 5 Cancelar returns 7). HTML dialog supplies modal focus containment; close it before removing its DOM node to restore the opener. Source control geometry comes from the generated layout; missing captions/assets are assumed in docs/evidence/message-proposals.json (Q-12), not recovered facts. Clipboard, native sounds and remaining chrome are still pending; no full dialog parity is claimed.

useDialogs().resource adds resource-state.ts/resource-dialog.tsx to the same queue. Button values are explicit or their 1-based index; Escape returns the cancel button's value and current input, while direct close returns the raw cancel index and original input. Explicit result/input replaces source variant mutation; callers must copy the returned input even on cancellation when the source does. Text/checkbox inputs and CRLF-triggered multiline text are supported; typed masks/coercion, automatic input flags, calculator and images remain pending U-W0075A5-01/04/05. Destructive callers must supply a safe index per ADR-006; no resource parity rows are verified yet.

dialog-metrics.ts now ports WINDEVMESSAGEBOX's 600-unit text cap, icon/button minimums, height adjustment and centered buttons; resourceButtonGeometry measures each caption with the source 80px minimum, 24px padding and 12px gaps. Browser font measurement replaces TexteLargeur/TexteHauteur after fonts load; font/wrapping/DPI and minimum-title clipping remain assumed under the existing dialog U items. The in-app viewport supplies the resource width cap (ADR-003). Resource text/input sizing is implemented in resourceGeometry below. dialog-metrics.test.ts and long-content browser flows check the actual helpers/renderers; no visual/native parity follows from them.

resourceGeometry now follows CalculeMeilleureDimensionTexte's ten-pass limit, ratio stops, frame minimum/cap, input reservation and 16px right margin; initial CRLF input height is measured once, as InitChampSaisieOuInterrupteur does. Label width-stretch and measured target input insets remain marked U-W0075A5-01/05 fallbacks because native metadata is absent. Long resource text/input flows exercise the real renderer and exact returned input; typed masks, optional flags, icon rendering and native/visual acceptance remain open.

VersPressePapier in WINDEVMESSAGEBOX uses message-clipboard.ts: messageClipboardText preserves the mapped separator/CRLF format and raw message text; writeMessageClipboard delegates to src/infrastructure/clipboard.ts and returns the platform result without adding a new error dialog (the source ignores its result). dialogs.tsx connects the actual BTN_Copier_caché and copy event; the keyboard route is the assumed ADR-003 default, not decoded metadata. Browser tests exercise the real copy-event handler with a DataTransfer; they do not touch the desktop clipboard or prove native clipboard acceptance.

## Implemented database foundation

HFSQL export → PostgreSQL: apps/server/src/db/column-mapping.v1.json names every field and conversion; legacy-import.ts exports convertCell/importLegacy/reconcileLegacy. Values cross this import boundary as exact strings, NULL or bytes, with typed provenance. migrate.ts owns transactional migration/checksum checks. legacy-import.test.ts exercises real PostgreSQL, rollback/retry, quarantine, precision, duplicate identities and restore; dry-run.ts reconciles the full copied dataset. This establishes import representation only; domain arithmetic and workflow write patterns above remain to implement in their owning stages.

# Foundation-only controls

The temporary foundation status page is not a migrated legacy window and has no visual parity claim. Its non-legacy identifiers are foundation-preview (development fake-backend banner), foundation-inspect (metadata command button), foundation-info (validated metadata result). All are removed/replaced by the skin-kit launcher when that stage is ready. Its Portuguese error is a developer diagnostic, not an accepted replacement for a legacy message.

ui-check.config.json lists the message dialog checkpoint with explicit pending controls and its missing visual reference. Configuration or a passing subset check never means full legacy coverage. The independent foundation flow tests the temporary page only. Native_info exposes build metadata; API liveness exposes process status, not database readiness. No business workflow, data access or permission is stubbed by these diagnostics.

The DEV-only `/?skin=controls` fixture exercises WdFrame/WdButton/WdEdit using selected generated WIN_Form_Clientes controls. It is a component gallery, not the customer form: Validar counts clicks and Cancelar clears fixture text. Non-legacy identifiers: skin-fixture-A/B, skin-frame-A/B, skin-reopen, skin-disable, skin-clicks. Portuguese chrome accessibility labels are fixture/UI accessibility text, not extracted captions. Two instances prove local callbacks/state without native IPC. Component-region scores live in docs/evidence/visual/skin-components.json; full-window coverage/visual parity remains unclaimed.

The same gallery now includes editable/read-only WdMemo and WdTable from the customer layouts. Table fixture IDs are listed in docs/screens/WIN_Table_Clientes.md. Synthetic stable string IDs exercise selection/reordering/activation; header clicks report the qualified column without inventing sorting semantics. Column search, resizing/reordering/saved configuration, masks, skinned scrollbars and HFSQL coupling remain pending. Component scores do not close those gaps.

The message fixture exercises awaited result values and concurrent request queuing, with captions/assets explicitly assumed under Q-12. No business mutation occurs. Its non-legacy IDs and pending source features are listed in docs/screens/WINDEVMESSAGEBOX.md. A captured screenshot without a legacy reference is unscored, never a visual pass.

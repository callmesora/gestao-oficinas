# Screens and navigation

The [mapping index](README.md) links all 53 window maps and specs: 51 dossier application windows plus WINDEVDIALOGBOX and WINDEVMESSAGEBOX. The two WDFAA skin windows have text sources but no dossier entries; their missing designer evidence remains explicit.

The generated [navigation map](../navigation.md) records literal source call sites. Encoded action groups and compiler-backed report references supplement that map in the [answer sheet](../evidence/encoded-actions.md). A recorded proposed action is assumed until confirmed, even when its name looks self-explanatory.

The main menu opens or activates lookup/list windows and repair/material/labor workflows. Selector windows return business codes into callers' shared buffers, with caller-specific continuation rules. Modal Open/Close return values and nonmodal OpenChild lifetimes must be retained; one application's window behavior cannot be inferred from another's similar designer layout.

No screen was implemented. Designer images and source scale drawings are under ../evidence/images/. Runtime row selection, keyboard behavior, dynamic states, concurrent refresh and human visual approval remain recorded U questions where not established by source.
